Kubernetes, sem peso.

Leme é uma IDE desktop para Kubernetes: veja e gerencie seus clusters com uma interface rápida, nativa e que consome uma fração da memória.

Tudo o que você usa no dia a dia

Feito para quem opera Kubernetes: das listas ao vivo ao diagnóstico de por que um pod está reiniciando.

Vários clusters

Lê o seu kubeconfig (incluindo SSO, exec plugins e certificados). Adicione clusters colando a configuração e troque entre eles sem reiniciar.

Qualquer recurso, ao vivo

Workloads, config, rede, storage, RBAC e Custom Resources, atualizados em tempo real. Busca com regex, filtro de namespaces e colunas configuráveis.

Logs e shell

Logs ao vivo por container (inclusive da execução que caiu), terminal dentro do container, shell root no node e terminal local já apontando para o cluster certo.

Por que reiniciou?

OOMKilled, liveness probe, CrashLoopBackOff, imagem que não baixa: o Leme cruza status e eventos e explica a causa em português.

Métricas

CPU e memória por pod, node e container, com requests e limits no gráfico. Funciona com o metrics-server do cluster.

Editor YAML seguro

Buscar e substituir, multi-cursor, diff contra o que o servidor gravaria (dry-run) e proteção contra sobrescrever mudanças de outra pessoa.

Helm

Releases, histórico de revisões, values e rollback para qualquer versão, direto do app, sem precisar do helm instalado.

Ações rápidas

Escalar, reiniciar (rollout), excluir em lote, cordon e drain de nodes e edição de ConfigMaps e Secrets direto no painel.

Leve de verdade

Usa o WebView do próprio sistema, só busca dados das telas abertas e pausa quando a janela está minimizada.

Download

Escolha o seu sistema. Os arquivos vêm da última versão publicada no GitHub, com checksums SHA-256.

macOS

macOS 12 ou mais novo · Apple Silicon e Intel
Primeira abertura

O app ainda não é assinado pela Apple, então o macOS bloqueia a primeira abertura (“A Apple não pôde verificar…”). Libere uma vez:

  1. Abra o .dmg e arraste o Leme para Applications.
  2. No Terminal, rode:
    xattr -dr com.apple.quarantine /Applications/Leme.app
  3. Abra o Leme pelo Launchpad ou Spotlight.

Sem Terminal: tente abrir o app, depois vá em Ajustes do Sistema → Privacidade e Segurança e clique em “Abrir Mesmo Assim”.

Windows

Windows 10 ou 11 · 64 bits
Primeira abertura

Se o SmartScreen avisar, clique em “Mais informações” → “Executar assim mesmo”. O instalador usa o WebView2, que já vem no Windows 10/11.

Linux

Ubuntu 22.04+, Debian 12+, Fedora 36+ · x86_64 e ARM64
Como instalar

Binário: execute uma vez e ele aparece no menu de aplicativos, sem sudo.

chmod +x leme-*-linux-amd64
./leme-*-linux-amd64

Ou o pacote: sudo apt install ./leme_*_amd64.deb. Requer WebKitGTK 4.1 (libwebkit2gtk-4.1-0).

Seus clusters, suas credenciais

Uma ferramenta que guarda acesso a produção precisa ser fácil de auditar. O código é aberto e o app foi pensado para não vazar nada.

  • Sem telemetria. Nenhum dado de uso, nenhuma conta, nenhum servidor intermediário.
  • Credenciais locais. Usa o seu kubeconfig; configs coladas ficam numa pasta privada (0700) e somem quando você remove.
  • Interface isolada. Content-Security-Policy impede a interface de carregar código ou enviar dados para fora.
  • TLS sempre verificado e dependências checadas a cada build (govulncheck, npm audit, assinaturas do registro).
  • Builds reproduzíveis no GitHub Actions, com checksums publicados em cada versão.

Compile você mesmo

Go no backend (client-go), Vue 3 + TypeScript na interface, empacotado com Wails. Contribuições são bem-vindas.

Ver o código 
# requisitos: Go 1.26+, Node 20+
go install github.com/wailsapp/wails/v2/cmd/wails@v2.16.0

cd apps/desktop
wails dev      # desenvolvimento com hot reload
wails build    # gera o app em build/bin
